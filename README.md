# Alnair Studio | استوديو النيّر

A bilingual (English / Arabic) one-page website for **Alnair Studio**, a Saudi studio for UI/UX design, web and mobile development, Supabase back-ends and AI integration.

موقع تعريفي من صفحة واحدة بالعربية والإنجليزية لـ **استوديو النيّر**.

**Live:** https://abomosaa.github.io/alnair-studio/

> *Alnair* (النيّر, "the bright one") is a star whose international name comes from Arabic: a guiding light for the "night desert" identity.

## Highlights

- **Bilingual:** one-click EN / ع toggle that swaps all copy and flips the layout to RTL. The choice is remembered, and `?lang=ar` opens Arabic directly.
- **"Night desert" design:** sand, copper and gold tones with a Sadu-inspired pattern.
- **Interactive hero:** a diamond grid that lights up under the cursor, and a Design → Code → Live demo window.
- **Sections:** services, AI use cases, process, stats, tech stack, industries and FAQ.
- **Contact:** a form that sends the request through WhatsApp, plus phone, email and social links.
- **Responsive and accessible:** works on all screen sizes and respects reduced motion.

## Tech

A single `index.html` file, with no build step and no dependencies. It uses plain HTML, CSS and JavaScript, with Google Fonts (Fraunces, Inter, IBM Plex Sans Arabic).
